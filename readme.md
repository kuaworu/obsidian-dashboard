# obsidian dashboard

### about the project

a starting page for obsidian featuring a set of widgets designed for task planning, goal tracking, and habit monitoring.

### nb! based on [obsidian dashboard gallery](https://github.com/czabransky/obsidian-dashboard-gallery) 
the design is based on the komorebi layout, with further widget improvements and personal customization.

the project uses the encore theme along with the following plugins: dataview, tasknotes, hearth, obsidian style settings, and background image.

## installation

1. make sure that javascript queries are enabled in the dataview plugin settings.
2. copy `obsidian-dashboard.md` to the root of your vault.
3. copy all css files into the `<vault>/.obsidian/snippets/` folder.
4. open settings - appearance - css snippets and enable the five css files.
5. open `obsidian-dashboard.md` and switch the note to reading view.
