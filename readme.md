# obsidian dashboard - черновик проекта

### о проекте

персональная стартовая страница для obsidian с набором виджетов, благодаря которым можно планировать задачи, отслеживать планы и следить за привычками.

### nb! за основу взят [obsidian dashboard gallery](https://github.com/czabransky/obsidian-dashboard-gallery). с проекта было взято оформление komorebi, а от него уже улучшение виджетов и кастомизация под себя.

---

## возможности

- часы и дата;
- календарь;
- добавление нескольких задач на день с временем начала и окончания, заголовком и описанием;
- список всех задач;
- spotify-плейлист;
- трекер привычек.

## установка

1. установите и включите плагин dataview в obsidian.
2. в настройках dataview разрешите javascript queries.
3. скопируйте `obsidian-dashboard.md` в корень своего vault.
4. скопируйте все css файлы в папку `<vault>/.obsidian/snippets/`.
5. откройте settings - appearance - css snippets и включите пять css файлов.
6. откройте `obsidian-dashboard.md` и переключите заметку в режим чтения.
